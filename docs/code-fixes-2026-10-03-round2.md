## 额外风险的处理与保留边界

- **R01 后台资源：** TaskRunner 返回取消句柄，默认总量上限 16，默认 900 秒请求超时取消；环境配置的 worker 数限制为 1–8。
  释放本地记录、删除 WCL 记录、替换索引任务、重置加载状态、关闭连接测试会取消任务。
  同一 URL 在下载中重复查询会选中已有任务。已取消任务在收到停止确认前仍计入容量，防止取消/重提绕过限制。
  取消是协作式：已发出的 HTTP 请求等待响应或网络超时，不会承诺立即中断系统 I/O。
  未引入独立高优先级池、强制终止单任务或完整进程 RSS 监控。
  WCL 已完成结果和收藏结果仍按现有产品策略保留，长期会话的内存容量仍需真实大日志基准。
- **R02 索引性能：** 完整旧前缀校验现在逐块报告进度，并支持取消，继续检测同路径改写。
  64 MiB 本地合成日志测得冷索引约 0.198 秒、缓存校验约 0.078 秒，分别有 29/10 次进度更新并结束于 100%。
  缓存命中仍读取旧前缀；这组结果不代表多 GB 日志、机械盘或网络盘性能。
- **R03 推断说明：** 无额外证据的凝视解除输出 unknown；附身时间附近的解除标为推定追上。
  炸弹保留 aura_end 依据，日志标明爆炸时间推定；扇形观测不足的球记录补推数量。
  这些修改提升可解释性，实际机制仍需脱敏真实日志对照。
- **R04 入口边界：** Qt 和主窗口导入延后至 main 内 freeze_support 之后。
  实际源码入口形式的 spawn 子进程探针验证 imported_qt=false。
  没有执行 Nuitka 发布包运行验证。
- **R05 缓存与安全：** 可再生事件/索引缓存按各目录 512 MiB、30 天保留策略在写入后清理旧条目，
  新写入条目保留，因此单个超大条目可超过目录预算。清理不跟随条目符号链接、不处理 token 或凭证。
  Secret 的 QSettings 存储和本机 token JSON 按项目约定保留。
  未执行真实 WCL 请求、依赖漏洞联网扫描或多场大事件量的峰值内存压力测试。
